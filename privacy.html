Animal Mail Route: privacy

Lee esta página en español

Animal Mail Route is a game for young children. It has no ads, no accounts, no in-app purchases and no third-party analytics or tracking code. It never asks for a name, age, photo, location or contact details.

Stored on your device

The game keeps its progress in your browser's local storage: rounds played on each route, stickers earned, which letters need more practice, which animal friends each player met most recently (so friends can take turns), which letters each player's rounds use, and the parent corner settings, including the game's language. If you add players in the parent corner, each player's progress is kept separately, along with the animal picture and the optional name you choose for them; names never leave the device and are never part of play counts. Each language keeps its own progress. On a first visit the game reads the device's language setting to choose the game's language; this happens on the device and nothing is sent. This stays on the device and is never sent anywhere. "Erase" (one player) or "Erase everything" in the parent corner deletes it, as does clearing the site data in your browser. So the game can be installed and played offline, the browser also keeps a copy of the game's own files (pages, fonts, pictures and voice recordings). These are the game, not information about the child.

Play counts (off unless a parent turns them on)

The parent corner (press and hold the gear on the title screen) has a "Share play counts" setting. It is off by default. When it is off, the game sends nothing.

When a parent turns it on, the game sends one small message when play stops, with these totals:

WhatExample
Times the game was opened1
Rounds started on each routeroute 1: 3
Rounds finished on each routeroute 1: 2
Wrong houses tried on each routeroute 1: 4
Game version1.8

That is everything. The message has no device ID, no cookie, no time of day, and nothing about which letters a child found hard. Our server adds the totals into one row per day for everyone combined. It does not record IP addresses. Turning the setting off deletes any totals that have not been sent yet.

The server runs on Cloudflare Workers. Like any website host, Cloudflare handles the connection itself; we do not ask it to keep anything beyond the daily totals above.

Feedback (only if you send it)

The parent corner has a "Help improve the game" section, with buttons to report a wrong word or translation, report a problem, or suggest an idea. A button opens your own email app with a new message to the game's maker, clements.cody.j@gmail.com. The game sends nothing: you read the message, change it as you like, and send it yourself, or don't.

The message is prefilled with only the game version, the game's language and the screen size, so we can find the problem. It never includes anything about a child: no names, progress, stickers or practice letters. If you send it, we receive your email address as with any email; we use it only to reply, and we don't share it.

Volunteer voices (for adults)

Adults can offer to record the game's lines on the volunteer page, linked from the parent corner. Recording happens on the volunteer's own device, in the browser, after they allow the microphone. The recordings are kept in that browser on that device until the volunteer erases them ("Erase my recordings" on the page, or clearing the site data). The page uploads nothing and sends nothing anywhere: the volunteer saves the files and only what they choose to email us leaves the device. The page keeps the volunteer's settings (which voice, the optional name for the credits) on the device too. Children's information is never involved.

Fonts, voices and hosting

The game's fonts and any recorded voices are served with the game, so playing does not contact any other company. When no recording exists, the game uses the speech voice built into your device. The game itself is hosted on GitHub Pages, which, like any web host, receives the usual connection information when the page loads.
