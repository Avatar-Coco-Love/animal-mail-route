Animal Mail Route: privacy

Animal Mail Route is a game for young children. It has no ads, no accounts, no in-app purchases and no third-party analytics or tracking code. It never asks for a name, age, photo, location or contact details.

Stored on your device

The game keeps its progress in your browser's local storage: rounds played on each route, stickers earned, which letters need more practice, which animal friends each player met most recently (so friends can take turns), which letters each player's rounds use, and the parent corner settings. If you add players in the parent corner, each player's progress is kept separately, along with the animal picture and the optional name you choose for them; names never leave the device and are never part of play counts. This stays on the device and is never sent anywhere. "Erase" (one player) or "Erase everything" in the parent corner deletes it, as does clearing the site data in your browser. So the game can be installed and played offline, the browser also keeps a copy of the game's own files (pages, fonts, pictures and voice recordings). These are the game, not information about the child.

Play counts (off unless a parent turns them on)

The parent corner (press and hold the gear on the title screen) has a "Share play counts" setting. It is off by default. When it is off, the game sends nothing.

When a parent turns it on, the game sends one small message when play stops, with these totals:

WhatExample
Times the game was opened1
Rounds started on each routeroute 1: 3
Rounds finished on each routeroute 1: 2
Wrong houses tried on each routeroute 1: 4
Game version0.9

That is everything. The message has no device ID, no cookie, no time of day, and nothing about which letters a child found hard. Our server adds the totals into one row per day for everyone combined. It does not record IP addresses. Turning the setting off deletes any totals that have not been sent yet.

The server runs on Cloudflare Workers. Like any website host, Cloudflare handles the connection itself; we do not ask it to keep anything beyond the daily totals above.

Fonts, voices and hosting

The game's fonts and any recorded voices are served with the game, so playing does not contact any other company. When no recording exists, the game uses the speech voice built into your device. The game itself is hosted on GitHub Pages, which, like any web host, receives the usual connection information when the page loads.
