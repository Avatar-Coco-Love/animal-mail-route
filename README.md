# Animal Mail Route

A mail delivery game for preschoolers (about ages 3 to 5): drag each letter, animal picture or number to the right animal's house. Plain HTML, CSS and JavaScript, no build step.

Play: https://avatar-coco-love.github.io/animal-mail-route/ (once GitHub Pages is on)

- `index.html`: the whole game. Start with `HANDOFF.md`.
- `privacy.html`: privacy page.
- `TELEMETRY.md` and `worker/`: opt-in anonymous play counts (Cloudflare Worker).
- `audio/`: recorded voice clips (none yet).
- `fonts/`: Baloo 2 and Nunito, SIL Open Font License.
